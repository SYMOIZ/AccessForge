# frontend/

React + TypeScript website. Hosted on AWS Amplify.

| Look here | For |
| --- | --- |
| `src/pages/` | Each screen (Home, Playground, Policy, …) |
| `src/components/AccessGraph.tsx` | Access graph |
| `src/components/AppShell.tsx` | Navigation |
| `src/index.css` | Visual style |
| `src/auth.ts` | Cognito sign in |
| `src/api.ts` | Backend calls |
| `.env.example` | Required env var names |

```powershell
npm install
npm run dev
npm run build
```
